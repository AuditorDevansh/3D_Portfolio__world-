# 🌐 3D Portfolio World

[![Live Demo](https://img.shields.io/badge/Demo-3d--portfolio--world.vercel.app-brightgreen?style=for-the-badge&logo=vercel)](https://3-d-portfolio-world.vercel.app)

An interactive, immersive 3D portfolio experience built to showcase projects, skills, and creative work in a dynamic web environment.

🚀 **[View Live Demo](https://3-d-portfolio-world.vercel.app)**

---

## ✨ Features

- **Interactive 3D Environment**: Explore a canvas designed to showcase projects in 3D space.
- **Dynamic Project Cards**: Interactive cards with detailed project breakdowns and links.
- **Fully Responsive**: Optimized for high performance across desktop, tablet, and mobile browsers.
- **Smooth Animations**: Seamless transitions and camera controls for an engaging user experience.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) / React
- **3D & Graphics**: Three.js / React Three Fiber
- **Languages**: TypeScript, JavaScript
- **Styling**: CSS Modules / Custom Styling
- **Hosting**: [Vercel](https://vercel.com)
